# カスタマーグロース事業部 評価制度

営業（AIテレアポ事業部）の Dig 制度をベースに、カスタマーグロース（以下 CG）向けの
評価対象と Dig の生まれ方を定義する。**確定した運用値を反映済み**（粗利率50% / チャーンの扱い /
分配率 / インセン還元率5%）。

---

## 1. 考え方

営業と CG で「Dig の作り方」を揃える。

| | 営業 | CG |
| --- | --- | --- |
| 予算Dig | （役職ベース × 保険係数 × 按分 ＋ 座席代）× 予算係数4.0 | **同じ** |
| 成果Dig の源泉 | 新規契約の**初回契約期間の粗利** | **新たに生まれた粗利**（更新・アップセル） |
| 守りの評価 | — | **チャーン（解約による粗利の喪失）** |

予算Dig の算定式は営業と完全に同一（コストの4倍）。**変えるのは成果Dig の作り方だけ**。

### なぜ「新たに生まれた粗利」なのか
現行設計では、営業の評価数字は「初回契約期間分の粗利」で確定している。
つまり**その期間の粗利は営業に配り切っている**。
2年目更新・アップセルで生まれる粗利は、**その時点では誰にも配られていない**。
ここを CG の原資にすれば、二重計上にならず、契約の生涯価値を漏れなく評価できる。

```
契約の粗利
├─ 初回契約期間（例 1年目）      → 営業へ配分（現行どおり）
├─ 2年目以降の更新期間           → CG へ配分（＋初回営業へ一部）  ← 新設
└─ アップセル（追加回線・コール） → CG へ配分（＋初回営業へ一部）  ← 新設
```

---

## 2. 成果Dig の算定

### 2-1. 共通の考え方

```
成果Dig = 新たに生まれた粗利 × Dig転換率 × 分配率
```

- **新たに生まれた粗利** … 更新・アップセルで増えた売上 × 粗利率
- **Dig転換率** … 粗利をどれだけ Dig にするか。営業と揃えるなら 100%
- **分配率** … CG と初回営業で分ける割合（下記 2-4）

### 2-2. アップセル（追加回線数・コール数）

追加された分の**契約期間ぶんの粗利**を原資にする。

```
アップセル粗利 = (追加回線数 × 回線単価 + 追加コール数 × コール単価) × 粗利率 × 残契約月数
```

| パラメータ | 確定値 | 備考 |
| --- | --- | --- |
| 回線単価・コール単価 | 契約の実額 | 契約管理DBの明細から |
| 粗利率 | **50%** | 全商材共通（商材別に変えたくなったら設定化） |
| 残契約月数 | アップセル日〜契約満了 | 上限は設けない（要見直しなら設定化） |

> **例**: 回線を3本追加（1本5万円）、粗利率50%、残10ヶ月
> 15万円 × 50% × 10ヶ月 = **75万円** → Dig転換率100%なら 75万Dig が原資

### 2-3. 更新（2年目以降）

更新が確定した時点で、**更新期間ぶんの粗利**を原資にする。

```
更新粗利 = 月額 × 粗利率 × 更新期間（月）
```

> **例**: 月額30万円、粗利率50%、12ヶ月更新
> 30万 × 50% × 12 = **180万円** → 180万Dig が原資

初回契約期間と重ならないため、営業の評価数字とは競合しない。

### 2-4. 初回営業への分配

「最初にアカウントを開いた営業」にも分配する。**同じ原資を割る**（原資は増やさない）。

| 発生事由 | CG | 初回営業 | 考え方 |
| --- | --- | --- | --- |
| アップセル | **70%** | **30%** | 関係構築の土台は営業の功績 |
| 更新 | **80%** | **20%** | 運用品質の寄与が大きい |

> **例（アップセル75万Dig）**: CG 52.5万Dig / 初回営業 22.5万Dig

- 分配率は設定で変更できるようにする
- 初回営業が**退職済み**の場合は CG 100%（または事業部プールへ）
- 分配は Dig申請の「折半」と同じ仕組みで実装できる（既存機能を流用）

### 2-5. チャーン（解約）

**更新月での解約（契約期間の満了に伴う終了）はマイナスなし。途中解約のみマイナス計上する。**

| ケース | Dig |
| --- | --- |
| 更新月での解約（満了） | **0**（マイナスなし） |
| 途中解約 | **残存期間の粗利をマイナス計上** |

```
途中解約Dig = − ( 月額 × 粗利率50% × 残契約月数 )
```

> **例**: 月額30万・残8ヶ月で途中解約 → 30万 × 50% × 8 = **▲120万Dig**

満了での終了は CG の責任範囲外（顧客都合・事業判断）とみなし、途中解約だけを守りの評価に反映する。

## 3. 予算Dig（営業と同一）

```
予算Dig = （役職ベース × 保険係数1.2 × 按分 ＋ 座席代）× 予算係数4.0
```

- 役職ベースは給与レンジ表（役職 × A/B/C）から自動判定
- アルバイトは「実労働時間 × 時給」
- **CG専用の調整は入れない**

### 達成率の見え方（イメージ）

| 項目 | 金額 |
| --- | --- |
| 予算Dig（コスト×4） | 400万 |
| アップセル（CG分） | +52.5万 |
| 更新（CG分） | +144万 |
| 途中解約 | ▲120万 |
| **実績Dig** | **76.5万** |
| 達成率 | 19% |

---

## 3-2. インセンティブ（営業と異なる）

**営業は 20% 還元、CG は「達成から上振れた分の 5% 還元」。**

```
インセンティブ = max(実績Dig − 予算Dig, 0) × 5%
```

> **例**: 予算400万・実績500万 → 上振れ100万 × 5% = **5万**

還元率は組織設定の「インセン還元率」で持つ。未設定なら上位組織を引き継ぎ、
どこにも無ければ既定20%。**カスタマーグロース事業部に 5 を設定する**。

---

## 4. 実装に必要なもの

### 4-1. いま無いデータ

| 必要なもの | 現状 | 対応 |
| --- | --- | --- |
| **粗利率** | 無し | 商材（modelKey）ごとに設定として持つ |
| **更新履歴** | 無し | 契約管理DBに更新日・更新期間が必要 |
| **アップセル履歴** | 無し | 契約明細の増減差分、または契約管理DB側で記録 |
| **解約日・解約時の残存期間** | `status` のみ | 契約管理DBに解約日が必要 |
| **初回担当営業** | SP_CRM の担当者 | 契約に「初回営業」を固定保持する |

**契約管理DBへの依頼事項が増える。** 既に依頼予定の `division` / `lines` / `calls` に加えて、
`updated_at`（更新日）・`renewal_term`（更新期間）・`canceled_on`（解約日）があると自動化できる。

### 4-2. 新しい算定ルールの型

現在の `CalcRuleType` は 回線コール単価 / 初回発注1to1 / 月額基本料金割合 / 固定Dig の4種類。
ここに次を追加する。

| 追加する種別 | 算定 |
| --- | --- |
| `アップセル粗利` | (増分売上 × 粗利率 × 残月数) × 分配率 |
| `更新粗利` | (月額 × 粗利率 × 更新月数) × 分配率 |
| `チャーン損失` | (月額 × 粗利率 × 残月数) × −1 |

### 4-3. 段階的な進め方

| 段階 | 内容 | 前提 |
| --- | --- | --- |
| **1** | Dig申請フォームで CG も申請できるようにする（種別＝アップセル/更新/チャーン、金額は手入力、折半で営業へ分配） | **いま作れる** |
| **2** | 粗利率を商材ごとに設定 → 申請時に金額を自動計算 | 粗利率の確定だけ |
| **3** | 契約管理DBから更新・アップセル・解約を自動取込 | 契約管理DBの列追加 |

**段階1は契約管理DBの改修を待たずに開始できる。** 既存の Dig申請＋折半の仕組みで、
CG が「アップセル 90万Dig・折半相手＝初回営業・折半 27万Dig」と申請すれば運用が回る。

---

## 5. 確定した運用値

| 項目 | 確定値 |
| --- | --- |
| 粗利率 | **50%**（全商材共通） |
| チャーン | **更新月での解約はマイナスなし / 途中解約は残存粗利をマイナス計上** |
| 分配率（アップセル） | **CG 70 : 営業 30** |
| 分配率（更新） | **CG 80 : 営業 20** |
| インセンティブ還元率 | **上振れ分の 5%**（営業は20%） |
| Dig転換率 | 粗利 1円 = 1Dig（千円切捨） |
| アップセルの評価期間 | 残契約期間の全額（上限なし） |
| 初回営業が退職済み | CG 100%（分配率0%として扱う） |

### 未確定（運用しながら決める）
- チャーンのマイナスに下限を設けるか（例: 単月予算の −50% まで）
- 商材ごとに粗利率を変えるか
